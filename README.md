# Multimedia Portfolio

A multimedia portfolio showcasing digital art, 3D visualization, and post-production workflows. Built by Marcus Inigo S. Aristain.

## Projects Featured

- **Solar System in Blender**: A procedural 3D simulation generating planetary orbits, keyframes, and PBR textures using Python scripting within Blender.
- **Rotoscoping Workflow**: A frame-by-frame masking project isolating subjects through Adobe After Effects and CapCut.

## Technologies Used

- **HTML5 / CSS3 / Vanilla JS** for the front-end structure and interactivity
- **Bootstrap 5** for responsive layout and UI components
- **Blender (Python)** for automated 3D modeling and animation
- **Adobe After Effects / CapCut** for video post-production

## Features

- **Dynamic Video Backgrounds & Parallax**: Premium feeling UI with immersive video integration.
- **Optimized Video Delivery**: Video content re-encoded for the web (H.264/AAC with faststart for instant streaming) and configured with efficient preloading.
- **Interactive Modals & Data HUDs**: Deep dive into the technical details of the projects right from the UI.
- **Responsive Design**: Designed to work on mobile, tablet, and desktop viewports seamlessly.

## Setup

1. Clone the repository.
2. Serve the directory using any static web server (e.g., `python -m http.server`, or Live Server extension).
3. Open `index.html` in your browser.
